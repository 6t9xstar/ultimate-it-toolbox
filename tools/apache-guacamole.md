# Apache Guacamole

> Apache Guacamole is a clientless remote-desktop gateway that serves RDP, VNC and SSH sessions through a web browser.

## How to get it

Docker images (guacd plus the web app) or a source build

See the official site for current instructions — deployment steps change more often than this directory does.
