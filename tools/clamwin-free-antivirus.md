# ClamWin Free Antivirus

> ClamWin is a free, open-source antivirus for Windows based on the ClamAV engine, offering on-demand scanning (it does not include a real-time scanner).

## Install on Windows

```powershell
winget install --id ClamWin.ClamWin --exact
choco install clamwin
```

## Verification

- Package id confirmed against the live `winget` source on 2026-10-30.
- Licence string is copied from the package manifest, not inferred.
