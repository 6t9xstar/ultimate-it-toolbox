# Arch Linux

> Arch Linux is a minimal rolling-release distribution that you build up yourself, and its wiki is one of the best Linux references anywhere.

## How to get it

ISO installer, then the guided `archinstall` script or a manual install following the wiki

See the official site for current instructions — deployment steps change more often than this directory does.
