# Webmin

> Webmin is a long-standing web interface for administering Unix-like systems, covering users, packages, services, the firewall and many server daemons.

## How to get it

Add the official repository with the setup script from the download page, then install with `dnf` or `apt`

See the official site for current instructions — deployment steps change more often than this directory does.
