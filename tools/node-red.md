# Node-RED

> Node-RED is a browser-edited, flow-based programming tool for wiring together devices, APIs and online services, and is popular in IoT.

## How to get it

npm package or Docker image; needs Node.js, which has its own card

```bash
npm install -g --unsafe-perm node-red
```

See the official site for current instructions — deployment steps change more often than this directory does.
