# Bulk Crap Uninstaller

> Bulk Crap Uninstaller is a free and open-source uninstaller utility for Windows. It helps users remove unwanted programs and clean up their system by uninstalling multiple applications at once.

## Install on Windows

```powershell
winget install --id Klocman.BulkCrapUninstaller --exact
choco install bulk-crap-uninstaller
```
