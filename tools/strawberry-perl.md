# Strawberry Perl

> Strawberry Perl is a Perl distribution for Windows that bundles a compiler and the usual CPAN build tools, so modules compile without extra setup.

## Install on Windows

```powershell
winget install --id StrawberryPerl.StrawberryPerl --exact
choco install strawberryperl
```
