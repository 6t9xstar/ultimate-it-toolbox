# Unlighthouse

> Unlighthouse crawls a whole site and runs Lighthouse on every page, giving a site-wide view of performance and SEO.

## How to get it

Run with npx; no install needed

```bash
npx unlighthouse --site https://example.com
```

See the official site for current instructions — deployment steps change more often than this directory does.
