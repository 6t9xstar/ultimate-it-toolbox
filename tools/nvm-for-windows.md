# NVM for Windows

> NVM for Windows is a node.js version manager that lets you install and switch between multiple versions of Node.js from the command line.

## Install on Windows

```powershell
winget install --id CoreyButler.NVMforWindows --exact
choco install nvm
```

- Package id confirmed against the live `winget` source on 2026-10-30.
