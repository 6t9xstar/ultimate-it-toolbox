## How to get it

npm dev dependency; requires an AI provider and browser/device setup; early-stage software with external model/device costs; FSL restricts competing commercial uses

```bash
npm install -D agent-qa
npx agent-qa init
```

See the official site for current instructions — deployment steps change more often than this directory does.
