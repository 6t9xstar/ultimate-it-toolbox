# NVDA Screen Reader

> NVDA is a free, open-source screen reader for Windows, used both by blind and low-vision users and by developers testing accessibility.

## Install on Windows

```powershell
winget install --id NVAccess.NVDA --exact
choco install nvda
```

- Package id confirmed against the live `winget` source on 2026-10-30.
