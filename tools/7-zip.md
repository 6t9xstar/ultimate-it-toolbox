# 7-Zip

> 7-Zip is a free and open-source file archiver utility. It supports several compression formats and provides a high compression ratio, making it a popular choice for file compression.

## Install on Windows

```powershell
winget install --id 7zip.7zip --exact
choco install 7zip
```
